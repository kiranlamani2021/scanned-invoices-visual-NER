DOCUMENT INTELLIGENCE

How invoice processing works

InvoiceAI turns scanned documents into reviewable structured data without hiding how each result was produced.

01

Prepare & read

PDFs are converted from their first page. OpenCV normalizes the document image before Tesseract reads the visible text and word regions.

02

Extract fields

Label-aware rules identify invoice number, invoice date, supplier, subtotal, tax, and total when those values are present in the OCR text.

03

Recognize entities

A Hugging Face token-classification model adds general named entities when available. Model output is shown separately from rule-based invoice fields.

04

Review & export

Missing values and processing limitations are flagged. Saved results can be searched in history and downloaded as JSON or Excel.

LOCAL WORKSPACE

Data and requirements

Invoice history, extracted OCR text, fields, entities, and warnings are stored in the local SQLite database. Original uploads are removed after processing; highlighted previews remain available for invoice details.

Image and PDF uploads up to 20 MB are accepted. PDF support requires Poppler; OCR requires Tesseract. See the project README for installation and configuration.
